Introduction

See Beyond Sight

Ally Vision is a wearable assistive navigation system that converts real-time 3D spatial data into tactile feedback on the user's forehead using a 5×5 dynamic pin-matrix, enabling visually impaired individuals to perceive obstacles without sight or sound.

Motivations

Why Ally Vision Exists

  • White canes detect only ground-level obstacles — missing overhead hazards, moving objects, and spatial context
  • Audio-based systems block environmental sound cues critical for safe navigation (traffic, voices, alerts)
  • Existing haptic devices are expensive ($2,000–$5,000+), bulky, and require extensive training
  • No existing product provides real-time 3D spatial mapping translated into intuitive tactile relief on the skin

🧠 Core Insight

The forehead is clinically proven as the optimal zone for tactile perception — the brain rapidly learns to interpret spatial height-maps pressed against it, achieving obstacle recognition within minutes through neuroplasticity.

— Bach-y-Rita & Kercel, "Sensory Substitution and the Plastic Brain", Trends in Cognitive Sciences

Problem Statement

The Challenge We Set Out to Solve

Millions of visually impaired individuals cannot safely navigate unfamiliar environments. Traditional aids detect only ground-level obstacles. Modern assistive technologies remain expensive, bulky, and audio-reliant — blocking the critical environmental sounds that blind users depend on for survival.

🦯

White Cane

Ground-level only. No overhead detection. No spatial context. ~1m range.

🔊

Audio-Based Systems

Blocks environmental sounds. Cognitive overload. Not intuitive for spatial mapping.

✋

Ally Vision (Ours)

Real-time 3D depth. Silent tactile feedback. Affordable. 6m range. No audio blocking.

Key Contributions

What We Bring

01

Bio-Inspired 7-Stage Architecture

A complete sensory substitution pipeline modeled after the human visual system: Eye → Visual Cortex → Nervous System → Muscle & Skin.

02

5×5 Dynamic Tactile Pin-Matrix

25 independent micro linear stepper motors with TMC2209 silent drivers delivering sub-millimeter, whisper-quiet pin displacement on the forehead.

03

Real-Time AI Spatial Fusion

YOLOv8n object detection + RGB-D depth fusion + RANSAC floor segmentation + ByteTrack multi-object tracking running at ≥20 FPS on edge hardware.

04

Safe Path Corridor Planning

3-sector walkable clearance analysis with 80cm human corridor envelope and automatic steering angle θ computation for dynamic path guidance.

05

"Abstract to Enhance" Philosophy

Converting high-density 3D point clouds into a low-cognitive-load 5×5 height matrix — preventing sensory fatigue while maximizing spatial awareness.

06

Systematic Literature Review

PRISMA-compliant SLR: 3,104 papers identified → 137 included across tactile feedback, sensory substitution, and navigation for VI from Scopus & WoS.

Objectives

Our Goals

📸

Real-Time 3D Perception

Achieve live RGB-D depth fusion with (X, Y, Z) metric coordinates at ≥20 FPS using edge AI with YOLOv8n ONNX.

🛡️

Safe Path Navigation

Detect walkable corridors (80cm width, 3m depth) using RANSAC ground plane extraction and 3-sector clearance analysis.

🧠

Hazard Priority Scoring

Multi-factor scoring: proximity weight (0.40), velocity (0.25), class severity (0.15), and path collision (0.20).

✋

Tactile Pin-Matrix Encoding

Map 3D obstacle depth to 0–5 physical pin height levels on a 5×5 matrix covering ±1.5m lateral, 0.5–5.0m forward.

⚡

Sub-100ms End-to-End Latency

Total pipeline from camera capture → AI processing → serial transmission → motor actuation under 100 milliseconds.

🧪

Human Subject Validation

5 blindfolded obstacle course trials comparing White Cane Only vs. White Cane + Ally Vision across transit time and collision count.

5×5 Tactile Height Matrix

Obstacle proximity mapped to pin displacement levels (0 = flush, 5 = peak hazard)

Row 1 = Far (5m) → Row 5 = Near (0.5m)  |  Col 1 = Left → Col 5 = Right

Pin Height Transfer Function

  • Level 0: Flush — Clear walkable space
  • Level 1–2: Distant obstacle (3.0 – 5.0m)
  • Level 3–4: Intermediate hazard (1.5 – 3.0m)
  • Level 5: Critical danger (< 1.2m)

🎯 Center column (Col 3) = User's forward walking path — kept flush unless direct obstruction detected.

Conclusion & Future Work

Key Findings & Next Steps

✓ Conclusions

  • Successfully built end-to-end sensory substitution pipeline: Camera → AI → Tactile Matrix → Forehead
  • Achieved 87.3% mAP@50 across 8 navigation-critical obstacle classes with YOLOv8n ONNX
  • Pipeline latency < 100ms validated — meeting real-time assistive device requirements
  • Safe corridor planning with 3-sector analysis achieves 90% accuracy on indoor test courses
  • 5×5 tactile matrix successfully conveys 3D spatial depth through physical pin displacement
  • Comprehensive SLR of 137 papers validated the approach against the state-of-the-art

🚀 Future Work

  • Outdoor GPS Integration: Combine with GPS waypoint navigation for outdoor route guidance
  • Larger Tactile Matrix: Scale from 5×5 to 7×13 pins for higher spatial resolution
  • Voice Command Layer: Add optional voice assistant for landmark identification and navigation instructions
  • Battery-Powered Wireless: Replace USB serial with BLE 5.0 for fully portable untethered operation
  • Extensive User Studies: Conduct IRB-approved studies with 50+ visually impaired participants
  • Miniaturization: Custom PCB and housing for commercial-grade wearable form factor
